# Pacific Wren annual indices from 1968 to 2022

An example of annual indices for Pacific Wren

## Usage

``` r
annual_indicies_data
```

## Format

### `annual_indicies_data`

A tibble with 55 rows and 4 columns:

- year:

  year of indices

- index:

  annual index

- index_q_0.025:

  confidence interval 2.5%

- index_q_0.975:

  confidence interval 97.5%
