# Pacific Wren bbs Smooth output from 1968 to 2022

An example of posterior draws from smooth component of BBS model for
Pacific Wren

## Usage

``` r
bbs_smooth_data
```

## Format

### `bbs_smooth_data`

A tibble with 55 rows and 4 columns:

- year:

  year of indices

- index:

  annual index

- index_q_0.025:

  confidence interval 2.5%

- index_q_0.975:

  confidence interval 97.5%
