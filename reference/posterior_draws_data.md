# Pacific Wren posterior draws output from 1968 to 2022

An example of posterior draws for Pacific Wren

## Usage

``` r
posterior_draws_data
```

## Format

### `posterior_draws_data`

A tibble with 55 rows and 4 columns:

- year:

  year of indices

- index:

  annual index

- index_q_0.025:

  confidence interval 2.5%

- index_q_0.975:

  confidence interval 97.5%
